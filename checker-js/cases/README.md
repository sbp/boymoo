# Checker cases

Each directory holds `verdict.txt` and may contain `library.txt`,
`statements.txt` and `proofs.txt`.
A missing input file is empty. The verdict file holds the expected first line.
Run `sh checker-js/test.sh [ENGINE]` from the repository root.

The table covers 97 conditions with 327 cases.
Section numbers refer to `spec/formats.md`, `spec/language.md`, `spec/logic.md`,
and `EDGE-CASES.md`.
