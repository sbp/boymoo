# H2 book responsibilities

| Books | Operations |
|---|---|
| `alists`, `arithmetic`, `alist-recognizers` | Association-list operations, recognizer lemmas, and integer and index arithmetic. |
| `search`, `book-logic`, `computation` | Rule indexing, reduction and case search, derivation requests, and evaluation of closed terms. |
| `finite`, `ordering`, `witnesses` | Finite tables, order relations, and witnesses for constraints. |
| `calculation`, `division`, `equivalence`, `products`, `modular` | Numeric normalization, reciprocal and quotient proofs, and transfer through equality or equivalence. |
| `list-counts`, `ranges`, `characters`, `sets` | List counts, affine decreases, character lists, and list-based set relations. |
| `compression`, `compression-lookup` | Compressed array construction, bounds, and lookup. |
| `recipes`, `binomial`, `numeric-recipes`, `ordinals` | Named proof recipes for list and state operations, binomial expansions, numeric recursions, and ordinal measures. |
| `tail-recursion`, `subsequence`, `book-recipes` | Bounded evaluation, indexed lists, and focused theorem recipes. |
| `books`, `api`, `open` | Admission and certificate search, proof entry naming, and reusable library sessions. |

[ORDER](ORDER) lists the books in dependency order. See [signatures](sig/)
for the inputs, results, and requests that cross book boundaries.
