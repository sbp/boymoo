# Proof search

The fact index stores claims and equations in separate ordered tables.
A new group of facts is first indexed on its own and then appended to the
context's index. The matching interface distinguishes an absent argument
head from an empty compound head.

The known-evidence table keeps the first Step recorded for a term when
search has several ways to establish it. Normalization can request proof
of a rewritten test. It receives the result and the Library with any
auxiliary lemmas from that request.
