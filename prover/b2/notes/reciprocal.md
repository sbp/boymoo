# Reciprocal arithmetic

The reciprocal recipes carry the Library through signed value cases.
The reply to a case request includes the Step and the Library at that
point. Rounding recipes use the same proof binding forms to propagate
supporting definitions and lemmas.

`grep -nE 'b2-reciprocal-(choose|results|return)' prover/b2/reciprocal.lisp` shows the proof operations. The command was run on 2026-11-23.
