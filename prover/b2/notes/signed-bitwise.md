# Signed bitwise proofs

The integer bitwise conjunction proof requests a floor type proof
when it needs one. The reply carries the resulting Library, which is
available to the remaining branches. The signed traversal visits
branches in order.

`grep -nE 'b2-signed-bitwise-(floor-request-p|integer-logand)' prover/b2/signed-bitwise.lisp` shows the proof operations. The command was run on 2026-11-23.
