# Removal clause processors

The proof of the removal processor uses the truth of the evaluated
disjunction. The case routine takes replies in true-then-false branch
order and uses the Library supplied with each reply.

`grep -nE 'b2-removal-(tests|disjoin-remove|arbitrary-hypothesis)' prover/b2/removal.lisp` shows the proof operations. The command was run on 2026-11-23.
