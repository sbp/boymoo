# Character-list results

The packing proof visits the values of the definition and combines the
character-list Steps for their cases. Decimal rendering uses the character
type of the digit conversion and the type of the accumulator.

`grep -nE 'b2-character-lists-(pack-characters|decimal-type|digit-type)' prover/b2/character-lists.lisp` shows the proof operations. The command was run on 2026-11-23.
