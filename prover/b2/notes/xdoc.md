# XDOC selector proofs

The argument partition proof establishes the type of a selected value
of the partition call. The leaf proof uses the signed evidence to open
the call and the matching projection Step to transport the result type.
The resulting Library contains the supporting projection lemmas.

`grep -nE 'b2-xdoc-(argument-partition-prove-leaf|argument-partition) ' prover/b2/xdoc.lisp` shows the proof operations. The command was run on 2026-11-23.
