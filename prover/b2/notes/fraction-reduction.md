# Fraction reduction

The common denominator construction installs a recursive definition
with a measure, then proves the fraction representation for its result.
The name of the representation lemma is paired with the Library that
contains the definition and lemma.

`grep -nE 'b2-fraction-reduction-(install-common|common-lemma) ' prover/b2/fraction-reduction.lisp` shows the proof operations. The command was run on 2026-11-23.
