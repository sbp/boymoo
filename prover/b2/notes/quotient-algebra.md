# Quotient algebra

`b2-quotient-algebra-reciprocal-of-pair` and
`b2-quotient-algebra-completed-product` return Steps paired with the
resulting Library. Multiplication by zero can add `B2-ZERO-PRODUCT`.
Subsequent proof steps use the Library that contains it.

`grep -nE 'b2-quotient-algebra-(reciprocal-of-pair|completed-product)' prover/b2/quotient-algebra.lisp` shows the proof operations. The command was run on 2026-11-23.
