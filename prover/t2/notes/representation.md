# Source lines and substitutions

`t2-books-split-lines` can retain each source line's terminator. The
basic terminators are LF, CR, and CRLF. The extended set also includes
character codes 11, 12, 28 through 30, and 133.

Negative indices in structural proof rules count arguments from the
right. The substitution map keeps pairs in first-insertion order and
uses the last binding supplied for each variable.
