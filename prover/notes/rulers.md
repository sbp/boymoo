# Hypotheses from ruler tests

A Rulers value holds signed tests and established proof steps.
Rulers recipe calls return the updated Rulers along with their answer.
Reuse that value so later lookups can cite the established evidence.
`rulers-rulers-with-proof` changes the library while preserving the
tests and the evidence.

`rulers-rulers-expand-first` stops at the first expansion whose
leading literal matches the requested term. For length cancellation,
`rulers-tail-number` can cite `SELF-LEN-NUMBER` in the slice and book
theories.
