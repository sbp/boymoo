# Recursive warrant proofs

`proof` is a Proof, `step` is a Step, and terms and bindings have the forms in `prover/sig/proof.md`. `comparison` is a Comparison and `selector` is a ChoiceRule from `witness.lisp`. `tests` is a list of `(term holds)` pairs in the order in which branches were entered. `holds` is `t` for the true branch and `nil` for the false branch.

| Function | Arguments and result | Failure |
|---|---|---|
| `(l1-recursive-has-lambda term)` | Whether evaluation of the term encounters a lambda application. | Malformed term. |
| `(l1-recursive-primitive-helpers proof body recursive)` | Names of the helpers called by `body`, excluding `recursive`, whose definitions call only primitives or `IF`. Names are ordered by package and symbol name. | A failure from the table lookup or the traversal of a term. |
| `(l1-recursive-introduce-implication proof hypothesis result)` | A Step introducing `hypothesis` as the antecedent of the implication with `result` as its consequent. | A failure from proof construction. |
| `(l1-recursive-list-wrapper proof function formals body)` | A Step opening the list-valued wrapper of `function`, whose definition has the given formals and body. | `UnsupportedApplication` for an unsupported wrapper or a failure from proof construction. |
| `(l1-recursive-scalar-wrapper proof function formals body)` | A Step opening a wrapper that returns a scalar on a singleton. | `UnsupportedApplication` for an unsupported wrapper or a failure from proof construction. |
| `(l1-recursive-list-wrapper-wrapper argument cons proof function)` | The wrapper equation under the given Boolean `cons` assumption. | A failure from proof construction. |
| `(l1-recursive-scalar-wrapper-open-at f arg tests proof other)` | The equation opening `f` at `arg` and `other` under the signed tests. | A failure from proof construction. |
| `(l1-recursive-scalar-wrapper-cons-result arg proof name other)` | The equation giving the helper's list construction at `arg` and `other`. | `UnsupportedApplication` for an unsupported helper or a failure from proof construction. |
| `(l1-recursive-scalar-wrapper-head-of step cons proof)` | The wrapper equation after substituting the list construction `cons` and projecting its head. | A failure from proof construction. |
| `(l1-recursive-recurrence-init proof comparison badge-test)` | A Recurrence for the comparison under the badge test. | `UnsupportedApplication` for unsupported recursive calls or wrappers, or a failure from term or proof construction. |
| `(l1-recursive-recurrence-at recurrence term argument)` | `term` with the recurrence's argument variable replaced by `argument`. | A failure from substitution. |
| `(l1-recursive-recurrence-replace-recursive-call recurrence term)` | `term` with recursive calls replaced by applications of the comparison's oracle. | A failure from term construction. |
| `(l1-recursive-recurrence-child-agreement recurrence tests)` | A Step proving agreement on the recursive argument under the given branch tests. | `UnsupportedApplication` for a missing cons test or a failure from proof construction. |
| `(l1-recursive-recurrence-local-agreement recurrence logical oracle tests)` | A Step establishing that a single unfolding agrees with the logical value when its child agrees. Pass `nil` for an omitted `logical` or `oracle` equality Step. | A failure from proof construction or `Fuel`. |
| `(l1-recursive-recurrence-comparison-equation recurrence)` | `(left right step)` giving the two quoted designators and their comparison equation. | A failure from application or proof construction. |
| `(l1-recursive-recurrence-when-child-agrees recurrence condition agreement)` | A Step proving `condition` using the `agreement` Step on its true branch. | A failure from proof construction. |
| `(l1-recursive-recurrence-induct recurrence left right selector picked)` | `(premise step)` giving the selected premise and the universal agreement Step. | A failure from proof construction. |
| `(l1-recursive-recurrence-locate recurrence picked premise bad-argument bad-failure)` | `(chosen step)` giving the selected argument and the implication Step for its failure. `bad-argument` is the argument and `bad-failure` is its failure Step when the badge fails. | A failure from proof construction. |
| `(l1-recursive-recursive-witness proof comparison test selector bad-argument bad-failure)` | `(count source)` giving the step count and complete text of the recursive witness, including its certificates in emission order. | A failure from application, proof construction or serialization. |

A Recurrence has the form `(:recurrence proof comparison argument badge agreement oracle logical function open-logic body child recursive-oracle one-step recurrence parent measure smaller agreement-child child-requirement)`. `open-logic` is a Step. `proof` contains the facts available to recurrence operations, including any certificates already admitted in the current witness. `l1-recursive-recurrence-with-proof` takes a Recurrence and the Proof with the available facts and returns the Recurrence with that Proof. The accessors `l1-recursive-recurrence-proof`, `l1-recursive-recurrence-comparison`, `l1-recursive-recurrence-argument`, `l1-recursive-recurrence-badge`, `l1-recursive-recurrence-agreement`, `l1-recursive-recurrence-oracle`, `l1-recursive-recurrence-logical`, `l1-recursive-recurrence-function`, `l1-recursive-recurrence-open-logic`, `l1-recursive-recurrence-body`, `l1-recursive-recurrence-child`, `l1-recursive-recurrence-recursive-oracle`, `l1-recursive-recurrence-one-step`, `l1-recursive-recurrence-recurrence`, `l1-recursive-recurrence-parent`, `l1-recursive-recurrence-measure`, `l1-recursive-recurrence-smaller`, `l1-recursive-recurrence-agreement-child`, and `l1-recursive-recurrence-child-requirement` each return the corresponding field. The accessors and `l1-recursive-recurrence-with-proof` return their values directly.

The constants are `*l1-recursive-user-application*`, `*l1-recursive-local-agreement*`, `*l1-recursive-step-comparison*`, `*l1-recursive-universal-agreement*`, `*l1-recursive-control*` and `*l1-recursive-atom*`.
