# Exponent proofs

`h3-book-exponent-type-and-bound` seeks an integrality Step and may
also give a bound. It can register sum lemmas before it concludes that
it has no integrality proof. The theorem recipe carries that Library
forward when the dispatcher tries another tactic.

`h3-book-exponent-nonzero-base-with-context` includes the Bounds
reached while proving the base nonzero.
